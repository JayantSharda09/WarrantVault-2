# WarrantyVault

Android App Development mini-project for CSE3142.

## Course-aligned concepts used
- Android Studio
- Kotlin
- XML layouts
- Views and ViewGroups
- TextView, EditText, Button, ImageView
- LinearLayout and ConstraintLayout-compatible XML structure
- RecyclerView
- User input validation and event listeners
- Activities and Fragments
- Explicit Intents and passing data between Activities
- Room persistence
- File storage
- WorkManager
- Notifications
- Error handling

## Main workflow
Dashboard -> Add Product -> Save -> RecyclerView -> Product Details -> Invoice Viewer

Warranty reminders are checked in the background by WorkManager.

## Notes
- Invoice selection is image-only in this version.
- OCR, AI, networking APIs, Firebase, sensors, and other non-required features are intentionally not included.
